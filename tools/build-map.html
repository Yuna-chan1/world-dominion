PETA / CARA MANUAL

🗺️ Bangun Peta Provinsi

Cara manual untuk membuat peta ±789 provinsi dari data Natural Earth admin-1. Hasilnya disimpan di browser (IndexedDB) — cukup sekali, lalu peta langsung tampil di halaman Peta Dunia.

1 · Unduh & bangun dari internet

Mengunduh GeoJSON Natural Earth (±40 MB) lalu membangun peta di browser ini. Butuh koneksi internet.

2 · Atau pakai file GeoJSON sendiri

Pilih file ne_10m_admin_1_states_provinces.geojson yang sudah diunduh (dari https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson).

3 · Unduh file data (untuk pengelola game)

Setelah peta berhasil dibangun, tombol ini mengunduh world-provinces.js. Simpan file itu ke folder data/ game agar semua pemain langsung mendapat peta tanpa membangun sendiri.
